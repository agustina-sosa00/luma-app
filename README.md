##Luma App

Esta aplicación tiene como objetivo que cualquier persona, pueda crearse una cuenta, iniciar sesion, y ver lugares donde puedan pasear, comer, disfrutar, etc.

Luma App, muestra lugares que estan cerca tuyo, permitiendo filtrar por categorias los lugares. 
Cada lugar tiene una vista de detalles donde se pueden agregar reseñas.

En la sección del perfil, hago uso de la camara, para poder cambiar la foto de perfil.
